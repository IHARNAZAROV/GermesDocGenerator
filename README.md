# Генератор договоров ГермесГарант

Десктопное приложение для агентства недвижимости **ГермесГарант** (Беларусь). Автоматически заполняет Word-шаблоны договоров данными из Excel-файла сделки — вместо ручного копирования.

---

## Возможности

- **Загрузка Excel** — открывает файл сделки, парсит данные по блокам (сделка, объект, собственники, покупатель) и заполняет форму
- **Генерация документов** — создаёт `.docx` файлы по выбранным шаблонам одним кликом
- **Предварительный просмотр** — просмотр заполненного документа перед сохранением
- **До 3 собственников** — динамические вкладки с иконками заполнения (✓/○), добавляются по кнопке
- **Представители (ПНД)** — блок доверенности раскрывается для каждого собственника при необходимости
- **Автоматический расчёт** — цена прописью, комиссия агентства, тип сделки
- **Валидация** — подсветка незаполненных обязательных полей, панель «Проверка данных»
- **Последние документы** — история открытых файлов Excel
- **Сохранение настроек** — папка для сохранения, выбор шаблонов и другие параметры сохраняются между сессиями (localStorage)
- **Автообновление** — Portable-версия проверяет GitHub Releases и обновляется без переустановки

## Шаблоны документов

| Группа | Документы |
|---|---|
| Риэлтерские услуги | Договор риэлтерских услуг, ЭКС-версия, физ. лицо — коммерческая |
| Договоры и соглашения | Задаток, Реклама, Конвертация валюты, Расторжение |
| Акты | Акт риелтерских услуг, Акт рекламных услуг |
| Запросы | Запрос на ПНД, Запрос в РСЦ (Справка), Запрос в РСЦ (Приватизация) |
| Прочее | Доверенность на представительство (ПНД), Согласие на обработку данных, Расписка о ключах |

Файлы шаблонов находятся в `templates/working/`. Плейсхолдеры используют формат `{{deal.number}}`, `{{owner1.fullName}}` и т. д.

## Стек

| Слой | Технология |
|---|---|
| Оболочка | [Electron](https://www.electronjs.org/) 43 |
| UI | Vanilla JS + HTML/CSS (без фреймворков) |

| Сборка | [electron-builder](https://www.electron.build/) |

## Быстрый старт (разработка)

```bash
# Установить зависимости
npm install

# Запустить в режиме разработки
npm start
```

Требования: Node.js 18+, Windows (для полной работы с файловой системой).

## Сборка дистрибутива

```bash
# NSIS-установщик + Portable .exe
npm run dist

# Только распаковать (без инсталлятора, быстрее)
npm run pack
```

Артефакты появятся в папке `release/`. Публикация на GitHub Releases выполняется автоматически при наличии `GH_TOKEN`.

## Добавление нового шаблона Word

1. Поместите файл `.docx` в `templates/working/`
2. Используйте плейсхолдеры `{{deal.*}}`, `{{owner1.*}}`, `{{property.*}}`, `{{buyer.*}}` — см. `config/placeholders.json`
3. Добавьте `<label class="tpl-item" data-template="your-key">` в `index.html`
4. Зарегистрируйте ключ в `TEMPLATE_FILES` в `main.js` (имя файла шаблона и выходного файла)
5. Реализуйте функцию генерации в `js/app.js` (по образцу существующих)

## Обновление полей формы (при изменении шаблона Excel)

Если структура Excel-шаблона сделки изменилась, пересканируйте его:

```bash
npm run scan excel/Шаблон_сделки_ГермесГарант_Заполненный.xlsx
```

Скрипт обновит `fields-config.json`. Перезапустите приложение — форма перестроится автоматически.

## Справочник риэлтеров

Файл `config/agents.json`. Каждый риэлтер:

```jsonc
{
  "id": "turko",
  "matchKeys": ["турко", "turko"],   // варианты написания в Excel (нижний регистр)
  "fullName": "Турко Ольга Ростиславовна",
  "initials": "Турко О.Р.",
  "position": "Риэлтер",
  "photo": "assets/olga-turko.webp",
  "attestationNumber": "1931",
  "attestationDate": "29.02.2024",
  "attestationExpiry": "28.02.2029",
  "cardNumber": "АВ 0028488",
  "cardDate": "26.06.2026"
}
```

`matchKeys` используются для автоматического определения риэлтера по имени в загруженном Excel.

## Автообновление

Portable-версия при запуске проверяет [GitHub Releases](https://github.com/IHARNAZAROV/GermesDocGenerator/releases). При наличии новой версии предлагает загрузить и заменить исполняемый файл без переустановки. Установочная (NSIS) версия использует стандартный механизм `electron-updater`.
